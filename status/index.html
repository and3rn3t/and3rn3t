          How this page works

          A Cloudflare Worker writes one data point for every API request and every MCP tool call (a fixed route name, a status and a time: no address, no user agent), and a scheduled check of the home page every five minutes. This page reads them back through the Analytics SQL binding, together with Cloudflare’s own request and Web Vitals data for this site, and caches the answer for five minutes.

          Nothing here says how many people visit or where they are. The same numbers are available as JSON, and to AI agents as the get_site_stats tool on the MCP server. The code is in the site’s repository.
