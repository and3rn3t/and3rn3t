Network Analytics Tool

A Python tool that queries the UniFi API directly to surface network-wide visibility — device inventory, traffic patterns, and security events beyond what the vendor dashboard exposes.

Source on GitHub

Overview

The official UniFi dashboard shows you what Ubiquiti wants you to see. This Python tool queries the controller API directly to pull richer data: per-device traffic histories, client fingerprinting details, event logs, and WLAN association records. It provided the foundation for building custom alerting on unexpected devices and tracking bandwidth patterns over time. The project is also a useful template for working with any vendor REST API that exposes more than its official UI shows.

Highlights

  • Surfaces UniFi data not accessible in the official dashboard via direct API queries
  • Device fingerprinting and per-client traffic history across network segments
  • Security event monitoring with alerting on unexpected device connections
  • Reusable pattern for any managed network vendor with a REST API
