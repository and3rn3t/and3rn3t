The site you're on: framework-free ES modules on GitHub Pages, a WebAssembly particle hero, and a Cloudflare Worker for the dynamic parts.

Live demo Source on GitHub

Overview

This portfolio is plain ES modules served straight from GitHub Pages: no framework, with a phased startup that lazy-loads everything beyond the critical path. The hero background is a particle flow-field written in AssemblyScript and compiled to WebAssembly. It falls back to a WebGL gradient, then to CSS, depending on what the device can handle. A small Cloudflare Worker covers what static hosting can't: Open Graph cards, a KV-backed view counter, a Turnstile-protected guestbook, and a cached feed of recent GitHub activity. A daily GitHub Actions workflow refreshes repository stats and the contribution calendar, so the numbers on the page stay current.

Highlights

  • Framework-free ES modules with a phased, lazy-loaded startup
  • AssemblyScript → WebAssembly particle flow-field with WebGL and CSS fallbacks
  • Cloudflare Worker + KV for OG cards, view counts, guestbook and live activity
  • Daily Actions workflow keeps stats and the contribution heatmap fresh
  • ESLint, Vitest, Playwright + axe-core and Lighthouse CI on every change
