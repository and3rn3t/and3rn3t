Apple Music DJ

A Python plugin for OpenClaw (a macOS automation launcher) that puts full Apple Music control in a keyboard shortcut — search, queue, and play without switching apps.

Live demo Source on GitHub

Overview

Apple Music DJ is a Python skill built for OpenClaw, a macOS automation and launcher framework similar to Alfred or Raycast. It bridges keyboard-driven workflows with Apple Music playback: one shortcut opens a search palette, another queues a track or album, another adjusts volume — all without touching the mouse or switching windows. The plugin uses an AppleScript bridge for library access where the Apple Music API doesn't reach, and demonstrates the composability of Python scripting with macOS platform APIs. It's a practical tool I use daily.

Highlights

  • Daily-use tool: keyboard-only Apple Music control from any app via OpenClaw shortcut
  • AppleScript bridge for library access beyond what the Apple Music API exposes
  • Demonstrates Python + macOS platform scripting composability
  • Plugin architecture integrates cleanly with OpenClaw's skill system
