The Hack: Ghost Protocol

A horror-themed hacking simulator and capture-the-flag game in Rust, with 26+ challenges for beginners and up.

Source on GitHub

Overview

A terminal hacking game with a horror story wrapped around it. There are 26+ capture-the-flag challenges, from Base64 and Caesar ciphers through file-system exploration, network analysis and SQL injection to reverse engineering, with hints aimed at people who aren't security folks yet, and a sanity meter that drops as you go deeper. It's written in Rust, with difficulty variants, a practice mode that generates challenges, and several save slots. The repository is archived.

Highlights

  • 26+ CTF challenges, from encodings to SQL injection and reverse engineering
  • Beginner-friendly hints, with a horror story and a sanity meter
  • Difficulty variants and a practice mode with generated challenges
  • Written in Rust
