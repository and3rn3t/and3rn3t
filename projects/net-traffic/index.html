Network Traffic Analyzer

A TypeScript dashboard running on a Raspberry Pi 5 that streams and visualizes live network traffic — top talkers, bandwidth trends, and anomalous connections in real time.

Source on GitHub

Overview

Network Traffic Analyzer is a self-hosted TypeScript service deployed on a Raspberry Pi 5 as a persistent home network sensor. It captures traffic metadata, computes per-device bandwidth totals, and pushes updates to a live dashboard via WebSockets — with no database and no polling. The architecture is intentionally lightweight: an in-memory streaming pipeline that stays responsive even on the Pi's constrained hardware. Built to complement UniFi data with packet-level visibility that the controller API doesn't provide.

Highlights

  • Runs continuously on a Raspberry Pi 5 as a persistent home network sensor
  • Sub-second WebSocket updates — no polling, no database overhead
  • Top-talker detection and connection anomaly flagging without commercial tooling
  • In-memory streaming pipeline tuned to run on constrained Pi hardware
