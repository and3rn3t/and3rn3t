HuggingFace Playground

Browse Hugging Face datasets and models, compare them, and try the Inference API, in one interface.

Source on GitHub

Overview

A learning tool for the Hugging Face ecosystem. It has a dataset browser with filters by task, language and size; a model explorer with model cards and code snippets; an API playground that sends requests to the Inference API and shows formatted responses; and a side-by-side model comparison. Built with React 19, TypeScript and Tailwind CSS. The repository is archived.

Highlights

  • Dataset browser and model explorer
  • Inference API playground with code examples
  • Side-by-side model comparison
