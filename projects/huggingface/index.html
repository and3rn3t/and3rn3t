Hugging Face API Sandbox

A TypeScript sandbox for the Hugging Face Inference API, comparing text generation, sentence embeddings, and zero-shot classification across open-source model families.

Source on GitHub

Overview

This project is a structured exploration of the Hugging Face Inference API, organised as a set of experiments rather than a single feature. Each module targets a different capability: text generation with instruction-tuned models, semantic search via sentence embeddings (without a vector database), and zero-shot classification for content tagging with no training data. A key focus is evaluating practical trade-offs — latency, output quality, and cost — between hosted inference and running models locally. The goal is to build enough hands-on intuition with open-source LLMs to make informed architectural decisions in production contexts.

Highlights

  • Semantic search via sentence embeddings — no vector DB required for small corpora
  • Zero-shot classification for content tagging with no labelled training data
  • Latency and quality benchmarks across hosted vs. local inference
  • Structured as reusable experiment modules, not a monolithic demo
