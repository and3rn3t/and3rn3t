iOS 26 Weather App

A native SwiftUI weather app built concurrently with the iOS 26 beta — a testbed for Apple's updated design system, WeatherKit, and Dynamic Island integration.

Source on GitHub

Overview

Built to stay current with Apple's platform as it evolves, this app tracks the iOS 26 design system and API changes in real time during the beta cycle. It uses WeatherKit for location-aware forecasts — Apple's privacy-respecting alternative to third-party weather APIs — and adopts the updated SwiftUI component system and visual language introduced in iOS 26. Dynamic Island integration provides glanceable weather state without opening the app. The project is less about the weather data and more about developing fluency with the latest Apple SDK while it's still in flux.

Highlights

  • Built during the iOS 26 beta — tracking live API and design system changes
  • WeatherKit integration: privacy-respecting forecasts with no third-party API
  • Dynamic Island glanceable weather state without opening the app
  • Adopts the updated iOS 26 SwiftUI component system and visual language
