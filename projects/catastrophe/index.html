CATastrophe Game

CATastrophe: A Mischief Simulator - experimenting with Unreal Engine and C++ game development.

Source on GitHub

Overview

CATastrophe is an experimental game development project using Unreal Engine and C++. Players control a curious cat navigating through detailed 3D environments, knocking objects off shelves, hiding in boxes, and generally causing adorable mayhem. The project serves as a learning experience in game development, 3D physics, and Unreal Engine's powerful capabilities. It showcases advanced C++ programming in a game development context and demonstrates skills in 3D modeling, physics simulation, and game design.

Highlights

  • Built with industry-standard Unreal Engine
  • Advanced physics simulation for realistic interactions
  • Detailed 3D environments and animations
  • Fun, engaging gameplay mechanics
