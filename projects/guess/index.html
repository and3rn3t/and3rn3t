Guess — Transparent Akinator

A 20-questions game that makes its decision tree fully visible as you play. Built to make information-theoretic narrowing tangible.

Live demo Source on GitHub

Overview

Guess is a TypeScript implementation of a 20-questions-style guessing game, with one key difference from Akinator: the algorithm is fully transparent. As you answer each question, the UI shows which candidates remain, the current confidence score, and why the next question was chosen — exposing the entropy-based selection logic in real time. The goal was to make constraint satisfaction feel intuitive rather than magical. It's live at andernator.com, works in any browser, and the decision tree logic is written from scratch with no external AI APIs.

Highlights

  • Live at andernator.com — playable in any browser, no install required
  • Decision tree and confidence score rendered in real time as you answer
  • Entropy-based question selection written from scratch — no external AI APIs
  • Makes constraint-satisfaction search intuitive by showing the algorithm's reasoning
