Home Automation Hub

A TypeScript home automation hub with real-time WebSocket device control, unifying multiple smart home platforms under one event-driven dashboard.

Live demo Source on GitHub

Overview

HomeHub is a self-hosted TypeScript application that centralises control of lights, locks, thermostats, and sensors across different smart home ecosystems. It uses a WebSocket-driven architecture for sub-second device state updates without polling, and a custom rule engine for time- and state-based automations. Strong TypeScript typing is applied end-to-end — device state, event payloads, and automation rules all have explicit schemas — making the codebase maintainable as integrations grow. The project reflects how I approach personal infrastructure: I'd rather build a well-architected tool than configure someone else's SaaS.

Highlights

  • WebSocket-driven real-time control — device state updates without polling
  • Custom automation rule engine for time- and state-based triggers
  • Strong TypeScript typing across device state, event payloads, and rule schemas
  • Self-hosted; no vendor cloud dependency for local device control
