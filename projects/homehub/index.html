HomeHub

An iOS-inspired smart home dashboard: Philips Hue control, live Arlo camera streaming, scenes and automations. A React 19 PWA on Cloudflare.

Live demo Source on GitHub

Overview

HomeHub is the control panel for my house, designed to feel like a native iOS app. It drives Philips Hue lights (colour included), streams Arlo cameras with DASH/HLS playback, and runs time-, condition- and geofence-based automations, which can also be built visually in a drag-and-drop flow designer. It's a React 19 PWA on Cloudflare Pages with Workers and KV behind it, and it keeps working offline from a local cache with optimistic updates.

Highlights

  • Philips Hue control with colour, and live Arlo camera streaming (DASH/HLS)
  • Automations with time, condition and geofence triggers, plus a drag-and-drop flow designer
  • Offline-first PWA: local cache, optimistic updates and a precaching service worker
  • Edge back end on Cloudflare Workers and KV
