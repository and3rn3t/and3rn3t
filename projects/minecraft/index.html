Self-Hosted Minecraft Server

A self-hosted Minecraft server with shell-scripted provisioning, automated backups, and a vanilla JS monitoring dashboard — infrastructure treated as reproducible code.

Source on GitHub

Overview

The interesting part of this project isn't Minecraft — it's the operational layer around it. A single provisioning script takes a fresh Linux host to a fully-configured, plugin-loaded server. Scheduled backups run with rotation policies to protect world data. A lightweight vanilla JavaScript dashboard surfaces real-time player count, server TPS, and JVM resource usage without any framework overhead. Everything is version-controlled: configs, scripts, and plugin manifests. It's the same infrastructure-as-code mindset I apply to production systems, applied to something I actually use.

Highlights

  • One-command provisioning: fresh host to fully-configured server via shell script
  • Automated backup pipeline with rotation — no manual intervention for world preservation
  • Vanilla JS monitoring dashboard: player count, TPS, and JVM metrics in real time
  • Config and plugin manifests version-controlled in git — fully reproducible
