Minecraft Server for Raspberry Pi 5

A Minecraft server stack for the Raspberry Pi 5: Docker deployment, automated and offsite backups, a Flask REST API and a React admin panel.

Source on GitHub

Overview

The interesting part isn't Minecraft, it's the operations around it. The stack is tuned for the Pi 5 (ARM64): Docker Compose with systemd units, scheduled backups with retention plus offsite copies to R2, S3 or B2, multi-world management, and plugin and mod management across Vanilla, Paper, Spigot and Fabric. A Flask REST API and a React 19 admin panel (with roles, API keys and OAuth) manage it, and the Pi pulls the newest green commit on main every five minutes. On top sits a layer of family gameplay features, from graves and lucky blocks to a bedtime and a Claude-powered chat companion, driven by an event bus that reads the server log.

Highlights

  • Docker Compose on a Raspberry Pi 5, started at boot by systemd
  • Scheduled backups with retention, plus offsite copies to R2, S3 or B2
  • Flask REST API and React admin panel with roles, API keys and OAuth
  • Auto-deploys the newest green commit on main every five minutes
  • Family gameplay features on an event bus that reads the server log
