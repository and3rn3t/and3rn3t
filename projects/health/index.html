Health Analytics Platform

A TypeScript + HealthKit platform that performs real-time gait analysis using iPhone LiDAR sensors.

Live demo Source on GitHub

Overview

This project combines iPhone LiDAR depth sensing with Apple HealthKit to analyze gait patterns without any wearable hardware. The iPhone becomes the sensor; a TypeScript web dashboard consumes live health data through the companion HealthKitBridge local HTTP server. The platform identifies walking irregularities, tracks wellness trends over time, and surfaces personalized insights — all processed on-device with no cloud intermediary. It's a real system with a live deployment, not a prototype.

Highlights

  • Live at health.andernet.dev — real iOS sensor data driving a web dashboard
  • LiDAR gait analysis without wearables: uses depth map data available on any modern iPhone
  • On-device HealthKit data pipeline — sensitive health data never leaves the local network
  • TypeScript frontend consuming live health data via the companion HealthKitBridge HTTP server
